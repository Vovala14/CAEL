# Pre-learned emoji vocabulary

The bundle includes eight previously learned entries, their integer class
counts, class maps, and normalized public reference pixels. Source URLs,
titles, licenses and recorded attribution are retained in
`emoji/learned_sources.json` inside the model bundle. The runtime stays offline.

Changes: original graphics were composited on white, fitted to 64x64, quantized
to the CA palette/codebook, and converted into integer per-cell class counts.
These learned-entry adaptations are provided under CC BY-SA 4.0; individual
reference graphics retain their recorded original licenses. CAEL's license
does not replace the separate terms of these third-party materials.
