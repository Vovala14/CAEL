# CAEL 0.3.9.1: native symbolic task interpretation

This source/runtime patch adds native, bounded interpretation of arithmetic, rule, ordering, location, string and table tasks while preserving the non-neural symbolic/count/automaton architecture. Five new task modules and one Assistant routing change are the exact qualified candidate bytes. The installed self-information hotfix is included, and version metadata now describes 0.3.9.1.

The larger resource archive remains byte-identical 0.3.7; no weights, protected choice.py/wordmath.py, CA kernels or image source/model bytes were changed. This is a custom Python runtime, not a Transformers checkpoint.

On the completed fresh synthetic 900-question study, the evaluated native candidate scored **777/900 (86.3%)**, versus **414/900 (46.0%)** for the unchanged 0.3.9 baseline. The newly worded half scored 327/450 versus 92/450. All 123 candidate abstentions count wrong. Known/adaptive families, maintainer/AI-assisted authoring and the neural models' fixed one-letter readouts limit interpretation. This is not a general chatbot victory or a Qwen comparison.

The model card links all nine results, questions, references and individual outputs. The old frozen leaderboard remains separate. Release verification reproduces already recorded replies after packaging; it adds no unseen-test score. Existing regression failures and finite-reader gaps remain disclosed.
