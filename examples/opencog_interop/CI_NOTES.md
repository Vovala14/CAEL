evidence states. Search and page reads are fully mocked; spelling tests use
local factual fixtures. These are conformance regressions, not benchmark
scores. No test suite is dropped and matrix fail-fast is disabled so both
Python versions finish. The workflow now also discovers the bridge tests.

without failures (two existing optional-module skips); the workflow's selected
pytest checks pass 44/44. The bridge has 13 passing tests and one explicitly
skipped real-AtomSpace test. The story-model reproduction hash matches the
inherited model and its authored evaluation completes. Repeated checks and
synthetic reproduction are not additional independent capability evidence.

Limits remain explicit:

  dictionary-unpacking merge or Unicode-uppercase-count recipes. Tests require
  those recipes to be refused; they do not count them as working functions.
  Two numeric examples use literal calls with their full unrounded expected
  values, within the existing literal-call checker contract. There is no
  native execution fallback or VM capability extension.
- The web reader conservatively reports a conflict for the overlapping Berlin
  Wall/concert dates in the retained fixture. It does not resolve the relative
  date clause. An untyped definition receives one quoted passage, not a claim
  that two publishers establish the same extracted answer. Neither behavior is
  reported as positive question-answering capability.
- The actual AtomSpace import test remains an explicit skip without bindings;
  the API double does not validate real AtomSpace compatibility.
- The bridge's two retained CAEL parser failures remain unchanged. No released
  weights, protected choice/word-math solvers, CA kernels, release tags, model
  publications or live worker are changed by this PR.
